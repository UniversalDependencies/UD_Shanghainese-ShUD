# Introduction

**UD Shanghainese-ShUD** is the first UD treebank for Shanghainese, a Wu Chinese variant spoken by approximately 14 million people. This treebank is annotated from a corpus with a focus on daily-use speech, which is a representative sample of contemporary Shanghainese. For details on the annotation method and pipelines, see the [paper](https://aclanthology.org/2025.udw-1.20/). Sentences are randomly split to train, test, and dev by ratios of 80%, 10%, 10%, respectively.

Shanghainese includes several geographical and historical variants. The focus of this treebank is on Middle and New Period Urban Shanghainese.
